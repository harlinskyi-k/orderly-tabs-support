# Orderly Tabs — support

Public support for the [Orderly Tabs](https://chromewebstore.google.com/detail/mcifpppneigmheohfhejbcjoaabjeghf) Chrome extension. The extension's source code is kept in a private repository.

- **Problems and ideas:** [open an issue](https://github.com/harlinskyi-k/orderly-tabs-support/issues/new/choose), or without a GitHub account use the [form or email](https://harlinskyi-k.github.io/orderly-tabs-support/report/).
- **Security reports:** privately, through the [Security tab](https://github.com/harlinskyi-k/orderly-tabs-support/security) or by email — see the [security policy](https://harlinskyi-k.github.io/orderly-tabs-support/security/). Please don't post vulnerabilities as public issues.
- **Privacy policy:** https://harlinskyi-k.github.io/orderly-tabs-support/privacy/

The pages are published with GitHub Pages from this repository: [`privacy.md`](privacy.md), [`security.md`](security.md), [`index.md`](index.md), [`report.md`](report.md).
